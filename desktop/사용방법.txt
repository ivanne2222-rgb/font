글결 · Windows TTF 편집기
========================

[실행]
1. Windows 10/11용 Python 3.12 또는 3.13을 설치하세요.
   https://www.python.org/downloads/windows/
   설치할 때 Add python.exe to PATH와 Tcl/Tk를 포함하세요.
2. ZIP을 폴더에 모두 압축 해제하세요. ZIP 안에서 바로 실행하지 마세요.
3. start.bat를 더블클릭하세요.
   처음 한 번 FontTools를 설치하므로 인터넷 연결이 필요합니다.
   이후에는 폰트를 편집할 때 인터넷 연결이 필요하지 않습니다.
4. 별도의 프로그램 창이 열립니다. 브라우저나 서버를 사용하지 않습니다.

[편집]
- TTF 열기 (Ctrl+O): 정적 .ttf 파일을 선택합니다.
- 글꼴 이름 / 스타일: 수정 후 '이름 적용'을 누릅니다.
- 글자 검색: 글자, 글리프 이름, U+0041 같은 코드로 검색합니다.
- 윤곽: 초록색 윤곽점을 마우스로 끌어 이동합니다.
  채워진 점은 윤곽점, 빈 점은 곡선 제어점입니다.
- 정밀 편집: 점을 선택하고 X/Y를 입력한 뒤 '간격 / 좌표 적용'을 누릅니다.
- 글자 폭 / 왼쪽 여백: 값을 입력하고 '간격 / 좌표 적용'을 누릅니다.
  LSB는 TTF 메트릭 값이며 윤곽 좌표를 이동하지 않습니다.
- 미리보기: 문장을 입력하고 '갱신'을 누릅니다. 윤곽선으로 표시됩니다.
- 실행 취소: 버튼 또는 텍스트 입력칸 밖에서 Ctrl+Z (최근 50회).
- 이 글자 초기화: 선택한 글자에 대한 수정 전체를 원본 상태로 되돌립니다.
- 다른 이름으로 저장 (Ctrl+S): 수정한 TTF를 새 파일로 저장합니다.
  간격/좌표 입력은 반드시 적용 버튼을 누른 뒤 저장하세요.

[지원 범위]
- TrueType glyf 테이블을 갖는 정적 TTF 지원.
- 기존 윤곽점 위치 편집 지원. 점/글자 추가와 삭제는 지원하지 않습니다.
- 복합 글리프는 폭/여백만 직접 편집합니다. 구성 요소 글리프의 윤곽을
  바꾸면 이를 참조하는 복합 글리프에도 반영됩니다.
- 가변 폰트, CFF OTF, WOFF, TTC는 지원하지 않습니다.
- 수정한 글리프의 힌팅과 폰트의 디지털 서명을 제거합니다.
- 이름 변경 시 영문 Windows 이름 레코드로 통일합니다.
  저작권/라이선스 등 관련 없는 이름 레코드는 유지합니다.
- 폰트 라이선스에서 수정과 재배포를 허용하는지 확인하세요.
- 폰트는 이 PC의 메모리에서 처리합니다. 외부로 전송하지 않습니다.

[EXE 만들기 — 선택 사항]
이 ZIP에는 소스와 실행기가 포함되어 있습니다. 완성된 EXE는 포함하지 않습니다.
Python 설치 후 build_exe.bat를 실행하면 Windows에서 EXE를 빌드합니다.
인터넷 연결이 필요하며 성공하면 dist\TTFStudio.exe가 생성됩니다.
생성한 EXE는 Python이 설치되지 않은 Windows PC에서도 실행할 수 있습니다.
코드 서명되지 않은 EXE는 Windows에서 확인 메시지가 나올 수 있습니다.
실제 Windows에서 빌드와 실행을 확인한 후 배포하세요.
